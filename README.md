---

## 🔹 Cómo usarlo

### Diagrama dinámico
- Para visualizar el **diagrama dinámico** de ejecución:
  1. Abrí tu archivo `.wlk`.
  2. Presioná **Run in REPL** desde Visual Studio Code o Wollok IDE.
  3. Se abrirá la simulación con el diagrama dinámico de objetos en tiempo de ejecución.

### Diagrama estático
- Los **diagramas estáticos** se encuentran en los archivos con extensión `.puml`.
- Estos diagramas muestran las clases y relaciones de manera estructural (UML).
- Podés abrirlos en VS Code con la extensión **PlantUML** y **Graphviz** instalados:
  - `Ctrl+Shift+P` → **PlantUML: Preview Current Diagram**
  - Exportar a PNG/SVG si lo necesitás.
